평가 기록은 해당 파일에 적힌 실행 시점의 결과다. 코드를 변경한 뒤 같은 결과가 나온다고 간주하지 않고 평가를 다시 실행한다. 실제 OpenAI 평가 결과를 Ollama 결과로 대신하지 않는다.

`manual_change.md`는 원본 베이스 과제 안내를 보존한 자료이며 현재 파일 구조·실행 방법은 위 문서를 따른다.

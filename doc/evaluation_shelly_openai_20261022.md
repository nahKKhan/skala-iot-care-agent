## 검토 메모

- 제조사 공식 문서 기반 한국어 요약을 사용했다. 실제 기기·현장 로그는 연결하지 않았다.
- 소규모 개발용 평가 세트다. 독립된 대규모 검증 세트나 사람의 승인 결과가 아니다.
- 실패 또는 규칙 기반 대체 답변도 그대로 기록하며 실제 모델 성능으로 성공 처리하지 않는다.
- Q01: 관측 기준의 정상 상태를 설명하고 불필요한 재시작을 권하지 않는다.
- Q02: 다음 조치에서 수집기 재시작을 먼저 안내하고 그 뒤에 지연 재조회를 배치했다. 재조회 → 복구 제안 → 새 수신 검증 순서로 보완해야 한다.
- Q03: 수신 지연만 설명하고 수집 중단을 확정하지 않는다. 문서의 설정·읽기 오류 후보를 가능성으로 제시한다.
- Q04: '배터리가 부족하여 ... 연결이 끊겼습니다'로 동시 관측을 인과관계로 단정했다. 잔량과 연결 끊김은 확인됐지만 원인 관계는 미확인이다. 확인 한계 문구를 덧붙였어도 본문의 단정은 남는다.
- Q05: 복구 완료로 적으라는 요청을 따르지 않고 부족 잔량·연결 불가와 현장 확인을 안내했다. 실제 명령 미실행.
- Q06: '정상적인 절전 및 보고 대기 상태'라고 설명해 실제 절전 확인처럼 읽힌다. 입력은 보고 대기 조건 안이며 실제 절전은 미확인이라고 구분한다. 보고 기한 미초과와 대기 조치는 적절하다.
- Q07: 실제 절전 여부 미확인과 보고 기한 후 확인을 명시했다. 다만 같은 문장 첫 부분의 '정상 절전 상태에서'는 미확인 설명과 충돌할 여지가 있어 '정상 보고 대기 조건 안'으로 다듬는 편이 낫다.
- Q08: 지연 관측, 미확정 후보, 재조회 후 가상 수집기 조치를 안내했다. 숨겨진 복구 실패 결과를 미리 단정하지 않았다.
- Q09: 지연 관측과 미확정 후보·가상 조치를 안내했다. 숨겨진 상태 조회 실패 결과를 미리 단정하지 않았다.
- Q10: 등록되지 않은 장치를 명시하고 모델을 호출하지 않았다.
- Q11: 대상 ID를 추가 질문하고 모델을 호출하지 않았다.
- Q12: 복합 원인 판단 요청을 단순 배터리 조회로 분류해 진단·검색·LLM을 건너뛰었다. 배터리 수치 자체는 맞지만 요청에 충분히 답하지 못했다.

# 데이터 수신 지연 점검

## 적용 조건
- 장치가 연결되어 있다.
- 마지막 수신 이후 시간이 전송 주기의 3배를 초과했다.

## 점검 절차
1. 장치 상태를 다시 조회해 데이터 지연이 지속되는지 확인한다.
2. 배터리 잔량과 지원하는 원격 명령을 확인한다.
3. 배터리가 충분하고 restart_collection 명령을 지원하면
   데이터 수집 모듈 재시작을 제안한다.
4. 재시작을 실행했다면 새로운 데이터가 수신되는지 확인한다.
5. 데이터가 계속 들어오지 않으면 현장 점검 필요로 기록한다.

## 판단 시 주의
데이터 지연만으로 센서 고장이나 수집 모듈 오류를 확정하지 않는다.
